# Jelajah Kata Ganti Nama — Tahun 4

Laman penerangan interaktif Bahasa Melayu untuk topik Kata Ganti Nama Diri dan Kata Ganti Nama Tunjuk. Reka bentuk ini mengadaptasi corak galeri imej daripada [gsap-threejs-codrops](https://github.com/J0SUKE/gsap-threejs-codrops): kandungan diperkenalkan secara berperingkat ketika skrol dan kad boleh diklik untuk membuka penerangan.

## Cara melihat

Buka `index.html` dalam pelayar yang mempunyai sambungan internet. GSAP dan fon dimuatkan daripada CDN. Imej latar sudah disertakan dalam folder `assets`.

## Cara menerbitkan

Muat naik keseluruhan folder ini ke hos laman statik seperti GitHub Pages atau Vercel, kemudian masukkan URL terbitan ke Google Sites melalui **Sisipkan → Benamkan → Mengikut URL**.

## Kandungan

- Penerangan ringkas tentang kata ganti nama.
- Kad interaktif untuk Kata Ganti Nama Diri dan Kata Ganti Nama Tunjuk.
- Contoh penggunaan dan lima soalan ringkas: kata ganti nama diri orang kedua dan ketiga, kata ganti nama tunjuk umum, serta kata ganti nama tunjuk tempat.

Projek sumber yang dirujuk menggunakan lesen MIT. Imej dalam `assets` dihasilkan khusus untuk projek pembelajaran ini.
